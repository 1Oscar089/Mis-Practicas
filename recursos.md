# RECURSOS A UTILIZAR

## Instalar en cada dispositivo
npm install en cada subcarpeta

### Frameworks de CSS

- TailWind CSS
    - npm install tailwindcss @tailwindcss/cli

### Resaltadores de Sintaxis

#### Resaltadores de Sintaxis Solo Lectura
- Shiki
    - npm install shiki
    - https://esm.run/shiki
- Highlight.js
    - npm install highlight.js
    -https://cdnjs.cloudflare.com/ajax/libs/highlight.js/11.9.0/highlight.min.js
    - Tema: https://cdnjs.cloudflare.com/ajax/libs/highlight.js/11.9.0/styles/atom-one-dark.min.css
- Prism.js
    - npm install prismjs
    - https://cdnjs.cloudflare.com/ajax/libs/prism/1.29.0/prism.min.js
    - Tema: https://cdnjs.cloudflare.com/ajax/libs/prism/1.29.0/themes/prism-tomorrow.min.css
- starry-night
    - npm install @wooorm/starry-night
    - https://esm.sh/@wooorm/starry-night
- Speed Highlight JS
    - npm install @speed-highlight/core
    - https://unpkg.com/@speed-highlight/core/dist/index.js
    - Tema: https://unpkg.com/@speed-highlight/core/dist/themes/default.css
- MicroLight.js
    - npm install microlight
    - https://unpkg.com/microlight

#### Herramientas de Exposición y Narración
- Code Hike
    - npm install @code-hike/mdx
- Bright
    - npm install bright

#### Editores de Código Interactivos
- Monaco Editor
    - npm install monaco-editor (o npm install @monaco-editor/react para React)
    - https://cdnjs.cloudflare.com/ajax/libs/monaco-editor/0.45.0/min/vs/loader.min.js
- CodeMirror (v6)
    - npm install @codemirror/view @codemirror/state (o npm install @uiw/react-codemirror para React)
    - https://esm.sh/@codemirror/view
- Ace Editor
    - npm install ace-builds
    - https://cdnjs.cloudflare.com/ajax/libs/ace/1.32.3/ace.js

#### Playgrounds e Interpretación en Vivo (Live Code Execution)
- Sandpack (CodeSandbox)
    - npm install @codesandbox/sandpack-react
